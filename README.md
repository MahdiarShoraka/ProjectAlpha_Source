# Unreal Engine 5 Slash Project

Developed as a course project to enhance proficiency in **C++ programming** and working with **Unreal Engine 5**.

---

## Key Features
- Enhanced input system for flexible player controls  
- AI navigation and enemy behavior  
- Combat system with advanced mechanics such as Motion Warping  
- RPG and economy systems including health, stamina, and looting  
- Chaos system integration for destructible environments  
- Niagara system for high-quality visual effects  

---

## Technologies Used
- Unreal Engine 5  
- C++
- UE Blueprints
- Chaos Physics  
- Niagara VFX
